# MP3 Tag Editor

A simple desktop app to edit an MP3's cover art, artist, title, and album.

## Requirements

- Python 3
- Dependencies:

      pip install customtkinter mutagen pillow

## Usage

Run the script:

    python mp3_tag_editor.py

Then select an MP3 file, edit the fields you want, and save.

## Features

- Edit song title, artist, and album
- Set or replace the cover image
